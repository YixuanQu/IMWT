1. The Idea & Cultural Context

The Live Museum of Movie Locations (LMML) — Rome Cinema Walk is an interactive digital humanities web application that explores the cinematic geography of Rome. Developed for the Information Modeling and Web Technologies course in the Digital Humanities and Digital Knowledge (DHDK) Master's degree program at the University of Bologna, the project examines how physical urban monuments transform into cinematic mythologies. By interweaving physical topography with narrative film history across 20 monumental landmarks and 6 iconic films (spanning from 1953 to 2023), LMML provides an educational, multi-layered journey that caters to casual tourists, cinephiles, and academic researchers alike.

The system operates on an object-oriented, highly structured unified metadata architecture defined in data.js. This data layer fulfills the strict Rich, Structured, Typed, and Uniform (RSTU) design constraints through two complementary layers:

  • Relational & Granular Model: The core data model defines a Many-to-Many architecture. Each location entity is indexed with geographic coordinates (latitude/longitude), exact street addresses, historical construction periods (from 509 BC to 2002 AD), seasonal visiting hours, architectural classifications, and curated multi-tier descriptive narratives. Furthermore, each location links to an array of cinematic appearances, specifying director, release year, diegetic status, scene descriptions, specific camera orientations (e.g., tracking low-angle shot, static symmetric composition), and high-resolution still frames.
  • Semantic Web & Linked Open Data (JSON-LD): In parallel with frontend JavaScript execution, the data is formally grounded in Schema.org vocabularies. The application semantically maps physical architectural monuments (LandmarksOrHistoricalBuildings, TouristAttraction) to creative works (Movie) and spatial actions (FilmAction), establishing the application as an open, machine-readable linked data node.

3. Overall Layout & Viewport Architecture

The interface avoids default browser scrolling through a strict 100vh viewport constraint canvas. The layout is architected into dedicated, isolated scroll zones that replicate native app-like responsiveness:

  • Spatial Division (Golden Ratio): In desktop view, the main screen splits horizontally following an optimized ratio — 38.2% dedicated to the interactive Leaflet map and control apparatus, and 61.8% dedicated to the scrollable narrative content canvas. On mobile viewports, this gracefully degrades into balanced vertical touch zones.
  • Predictable Vertical Flow: While visual styling shifts across eras, the structural layout remains strictly vertical and uniform across all themes: Location Profile (monument photo + technical metadata table + historical timeline) → Featured In (movie frame + film production table + flipbook navigator) → Three-Axis Content (interactive narrative passage) → On-Site Practicalities (Google Maps QR code and directions).
  • SPA State Routing: The application features a lightweight, zero-dependency client-side SPA router supporting three distinct views: Map Overview, Interactive Narrative Tour, and About/Documentation.

4. Tour Design & Dynamic Content Synthesis

The visitor experience is dynamically computed based on two core interactive systems:

  • Four Curated Narrative Routes: Visitors can explore Rome through four distinct walking orders selected via the top-right header menu. Historical Timeline organizes all 20 locations chronologically from Antiquity to Modernity; City Tour provides a geographic walking sequence through quintessential landmarks; Art Tour curates masterworks, museums, and palazzi; and Film Tour isolates iconic sets that have repeatedly hosted major productions. The route engine re-indexes map markers ($1 \dots N$), hides out-of-scope locations, updates chapter banners, and recalculates step navigation dynamically without data duplication.
  • Three-Axis Text Grid Synthesis: Rather than forcing static articles, each location features a synthesized text block computed along three independent pedagogical axes ($3 \times 3 \times 3 = 27$ variations per landmark):
    • Detail Length: Step-cycled via Read More / Read Less buttons (Brief → Mid → Long).
    • Audience Tone: Selected via inline tags (Kid / Young → Adult → Scholar).
    • Competence Level: Step-cycled via Too Easy / Too Difficult buttons (Introductory → Average → Advanced).
  • 3D Flipbook Carousel: Locations hosting multiple film productions (e.g., Trevi Fountain in Roman Holiday, La Dolce Vita, and To Rome with Love) feature a perspective-transformed 3D flip card system, allowing users to flip between film appearances in place.
  • On-Site Dynamic QR Generator: Each stop dynamically generates an on-the-fly QR code linking directly to Google Maps place queries using verified Italian names and addresses for physical walking navigation.

5. Four Cinematic Era Themes

The visual design does not mimic architectural eras, but rather celebrates the aesthetic history of world cinema itself. Driven by a single CSS Custom Property token architecture (--t-*), switching themes instantly recalculates typography, aspect ratios, color palettes, card frames, and map cartography:

  • 1. The Expressionist (1890s–1920s): Rooted in German Expressionism and early silent cinema. Characterized by extreme chiaroscuro contrast, pure black-and-white canvas, thick 3px brutalist bounding lines, zero corner radii, and a high-contrast B&W map tile filter. Stills adhere strictly to the classic 1.33:1 (4:3) Academy Ratio, and screenshot filters are completely disabled to preserve original production framing. Typography is set in IM Fell English.
  • 2. The Classic Studio (1930s–1950s): Inspired by vintage Hollywood and Italian cine-posters (e.g., Chaplin's Modern Times and The Kid). Utilizes warm aged-paper backgrounds (#eedc9a), rich scarlet accents (#d32215), heavy ink borders, and hard-edged 6px drop shadows. Stills are framed in 16:9 widescreen. Metadata tables are styled like vintage poster billing blocks, pairing bold condensed Oswald with elegant Dancing Script signatures.
  • 3. The New Wave (1960s–1980s): Drawing inspiration from French New Wave (Godard, Truffaut, Varda) and 1960s pop-art street poster collages. Features high-saturation primaries (Godard Red, mustard yellow, and cobalt blue), solid border frames with colorful offset shadows, and a saturated pop-art map filter. Stills adopt the standard theatrical 1.85:1 widescreen ratio. Typography pairs Oswald headings with clean Jost body text.
  • 4. The Digital Seamless (1990s–Present): Reflects contemporary sci-fi, VR holographic interfaces, and deep space aesthetics (e.g., Interstellar, Avatar). Built on deep void black (#030407), glowing cyan neon accents (#00f0ff), and high-contrast translucent glassmorphic panels (backdrop-filter: blur(16px)). Stills stretch into the expansive 2.35:1 Anamorphic CinemaScope Ratio. Typography pairs monospace HUD telemetry (Courier Prime) with ultra-clean modern sans-serif (Inter).
